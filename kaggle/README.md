# Kaggle

Gói huấn luyện được push lên Kaggle để chạy controlled retraining.

- `train.py`: tải dữ liệu huấn luyện, train XGBoost, xuất artifact và log metadata thí nghiệm.
- `kernel-metadata.json`: cấu hình kernel Kaggle và biến môi trường.

Đây là thư mục training chính đang được dùng trong flow retraining hiện tại.
